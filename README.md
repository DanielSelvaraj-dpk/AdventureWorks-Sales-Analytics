# AdventureWorks Sales Analytics

## 📊 Project Overview

An end-to-end sales analytics project using SQL Server, Microsoft Fabric, and Power BI to analyze customer behavior, product performance, revenue growth, and sales trends.

The project uses the AdventureWorks dataset to answer real-world business questions and provide actionable insights for decision-making.

---

## 🎯 Business Objective

The objective of this project is to analyze sales data and identify:

- Key revenue drivers
- High-value customers
- Customer growth and decline
- Customer churn risk
- Product performance
- Category performance
- Year-over-year revenue trends
- Revenue concentration
- Sales opportunities
